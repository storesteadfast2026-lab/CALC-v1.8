Freight Quote

POST {% url 'quote_api_v1' %}
{% csrf_token %}
Response 
Send a quote request to see the result.

Documentation

Request fields
Send client_code, the destination suburb, state and postcode, and the freight lines. Each catalogue line takes sku and quantity, with an optional product_id.
Options
Use from_address_id to choose the dispatch address. Set tailgate to YES or NO. Use cubic_margin_percent if the account allows a cubic margin.
Manual dimensions
If the account allows manual dimensions, set preselect_sku to NO and send quantity, freight_type, length_m, width_m, height_m, weight_kg and cubic_m3 for each line.
Response
Each entry in results includes carrier, service, estimate_ex_gst (price excluding GST), status and quote_status. Check warnings for any notices. Internal users receive the cost breakdown in details.

Freight Accounts

GET {% url 'freight_accounts_api_v1' %}
Response 
List the freight accounts you can access.

Documentation

Send the request without parameters. results lists the active accounts you can access, with a code and name for each. Use the account's code as client_code when requesting a quote.

Authentication

This page uses your calculator session. When using another HTTP client, send the session cookie. For quote requests, set Content-Type to application/json and send the value of the csrftoken cookie in the X-CSRFToken header.
